VIETNAMESE DOCX READER

1. Đặt một file DOCX lớn cạnh build.ps1.
2. Chạy build.ps1; script tự chọn file DOCX mới nhất nếu không truyền -Source.
3. Mở index.html bằng Chrome hoặc chạy server.mjs.
4. Mỗi Heading 2 trong file gốc sẽ trở thành một phần/chương.
5. Chọn voice tiếng Việt, sau đó bấm "Đọc chương".

Tên file DOCX không bị cố định; tiêu đề, khóa lưu tiến độ và danh sách phần được tạo theo file đang build.
